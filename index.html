How it works

Every vertical shares one method (the Build method): Scope it with competency questions, Discover the raw disagreements in your source material, Draft a first-pass structure, Resolve each conflict one at a time with a recommended answer, then Validate that nothing was silently dropped and every competency question is actually answerable. What differs per vertical is which conflicts are common and what the output should look like — see each vertical's own recipe.md.

Known gaps

This Turtle file uses the real FHIR namespace but a simplified triple structure — real FHIR RDF wraps every literal in a fhir:v blank node (e.g. fhir:status [ fhir:v "final" ]) for FHIR-tooling-specific reasons. This file uses plain literals for readability. The vocabulary is real; the serialization style is a disclosed simplification, not an inaccuracy about what FHIR models.

Full picture, including which conflicts have a worked example in ontology.ttl, is in the changelog.

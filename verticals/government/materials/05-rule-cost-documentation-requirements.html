Rule & Cost Documentation Requirements Register (excerpt)

Maintained by the County Clerk's compliance team. Each requirement has a "Satisfied by" field set once and rarely revisited. (raw export)

REQ-701 — Rule document currency

The Rule document linked from a Public Service record must reflect the current fee schedule and procedural requirements.

Satisfied by: the Rule document generated at the service's initial catalog entry.

The Rule document (PDF) linked from SVC-2201 was generated in 2022 and lists a $50 renewal fee. The Board of Supervisors approved a fee increase to $65 in early 2025. The linked document was never regenerated.

REQ-702 — Cost matches fee schedule

A service's listed Cost must match Finance's current, authoritative fee schedule.

Satisfied by: the Cost value entered at initial catalog setup.

SVC-2201's catalog entry still lists $50. Finance's fee schedule system shows $65, effective since the same 2025 increase referenced above.

REQ-703 — Annual service catalog review

Every Public Service record must be reviewed annually, including its competent authority, cost, and linked rule document.

Satisfied by: the review checklist's "confirm service description reviewed" checkpoint.

That checkpoint confirms someone read the description — it does not require reconciling competent authority, cost, or rule-document currency against their actual current systems of record.

Media / Real Estate

Amberlane Media

A fictional stock photo/footage licensing agency. Its asset registry, licensing agreements, constraint-drift records, rights/legal glossary, attribution/compliance requirements, and studio-booking/royalty process notes all disagree with each other — on purpose. This walkthrough resolves those disagreements into an ontology grounded in real, published vocabulary (ODRL) — the first vertical in this project built on deontic logic (permission/prohibition/duty) rather than descriptive class hierarchies.

Walk the Build process

Stage 0

Scope

Write the competency questions the ontology needs to answer, before touching any material.

 Stage 1

Discover

Inventory every term and conflict, without resolving anything yet.

 Stage 2

Draft

A first-pass class/relation structure — and why ODRL's deontic shape differs from every prior vertical.

 Stage 3

Resolve

Ten conflicts, one at a time, with a recommended resolution.

 Stage 4

Validate

Check nothing was silently dropped; produce the changelog.

Result

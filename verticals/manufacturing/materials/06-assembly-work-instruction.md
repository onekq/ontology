# WI-MTR100-01 — Mid-Drive Motor Assembly

Maintained by Production Engineering. Revision lettering on this document tracks *instruction*
changes only — it is not kept in sync with the product's own BOM revision (Rev B/Rev C). Last
updated 2024-03, before ECN-118 (Rev C rotor) and before ECN-124 (Controller rename).

## Station 1 — Stator Prep
Install STA-210 core and STA-215 windings into housing fixture. Torque FST-004 fasteners to
1.2 N·m. *(Does not specify FST-004 vs. FST-004-2 — operators use whichever is in the station 1
parts bin.)*

Cycle time: 6.0 min.

## Station 2 — Rotor Install
Install rotor per BOM. **QC checkpoint: confirm magnets present (visual check).**

Cycle time: 4.5 min.

## Station 3 — Controller Install
Install Controller Board Assembly (CTL-400). Connect Hall sensor harness, verify continuity.

Cycle time: 3.0 min.

## Station 4 — Housing Assembly
Install GSK-001 gasket, torque HSG-500 shells together per drawing DWG-HSG-500-C. Verify no
visible gap at seam.

Cycle time: 5.5 min.

## Station 5 — Final QC
Power-on functional test: confirm rotation, confirm no fault codes on controller. Package for
shipment.

Cycle time: 4.0 min.

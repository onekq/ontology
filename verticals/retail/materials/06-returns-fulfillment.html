Returns & Fulfillment Process Notes

Maintained by Warehouse Ops. Revision tracking on this document covers process steps only, not kept in sync with Marketing's storefront copy. (raw export)

Returns Processing Checklist

1. Receive return. Log tracking number, match to original order.
2. Inspect. Confirm item present, box present.
Does not verify the returned item's SKU/GTIN matches the original order — a wrong or substituted item passes this checkpoint identically to a correct one.
3. Disposition decision. Resellable-as-new → restock. Opened/used → refurbish-and-relist as "Refurbished." Damaged → dispose.
4. Process refund.
